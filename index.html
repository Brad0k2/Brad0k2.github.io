rclone-backup

A personal file backup setup

rclone-backup is a personal backup setup run by the owner of this GitHub account. It uses rclone, an open-source file transfer program, to copy the owner's own files from their own computer to their own Google Drive.

It is not a public product or service. Nobody else can sign up for it or use it, and it has no other users.
