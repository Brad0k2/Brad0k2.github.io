Privacy policy for rclone-backup

Last updated October 17, 2026

Who uses it

Only the owner of this GitHub account, with their own Google account. rclone-backup is not offered to anyone else.

What Google data it can access

Only files that rclone-backup itself creates in the owner's Google Drive (Google's "drive.file" permission). It cannot see, open, change, or delete any other files in that Drive.

How that data is used

Only to copy the owner's own backup files from their computer to their Google Drive and, if ever needed, back again to restore them.

What is collected, stored, or shared

Nothing. No personal information is collected or kept on any server, shared, or sold. There are no analytics, ads, or tracking. Files travel directly between the owner's computer and Google Drive, and the Google sign-in token stays on the owner's computer.

Google API Services User Data Policy

rclone-backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If anything here changes, this page will be updated first.

Contact

Through the GitHub account that hosts this page: github.com/Brad0k2.
